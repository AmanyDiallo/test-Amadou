À propos du jeu

Un site statique avec un backend dynamique.

FootQuiz utilise un frontend HTML/CSS/JS léger hébergé sur Amplify, et un backend Python FastAPI sur AWS Lambda pour générer des questions de quiz.

Comment ça marche ?

  • Front-end statique servi par Amplify
  • Backend via API Gateway + Lambda
  • Questions randomisées à chaque partie
  • Questionnaires de foot sur les grands championnats

Les points forts du quiz

Un jeu simple à utiliser, avec des questions qui changent, un score instantané, et une interface moderne.

Rapide

Une page légère, sans framework lourd, prête à être déployée rapidement.

Responsive

Design optimisé pour mobile et desktop, avec une navigation simple.

Évolutif

Tu peux ajouter des catégories, des scores, des questions en quelques minutes.
